# Исследование глобальных бирж

В проекте сравниваются две группы площадок:

- криптовалютные биржи;
- традиционные биржи деривативов.

Цель исследования — сопоставить биржи по доступным количественным показателям,
разобрать ограничения полученного рейтинга и сформулировать собственный итоговый
TOP-5 для каждой группы.

## Как устроена оценка

Исследование разделено на два этапа.

1. **Количественная модель** — воспроизводимый расчёт `Final Score` на основе
   нормализованных показателей и заданных весов.
2. **Мой экспертный итог** — независимая оценка с учётом характеристик, которые
   не вошли в формулу: специализации площадки, её роли на рынке, прозрачности
   резервов и дополнительных механизмов защиты пользователей.

Эти результаты показаны отдельно: экспертный итог не является второй
математической моделью и может отличаться от сортировки по `Final Score`.

## Структура проекта

- [`data/`](data/) — исходная Excel-таблица с собранными показателями;
- [`notebooks/`](notebooks/) — очистка данных, нормализация, расчёт рейтингов и
  визуализация в Jupyter Notebook;
- [`materials/`](materials/) — список использованных источников и дополнительные
  материалы;
- [`figures/`](figures/) — диаграммы для итогового отчёта;
- [`scripts/`](scripts/) — воспроизводимое построение итоговых диаграмм;
- [`ANALYSIS.md`](ANALYSIS.md) — итоговый текст исследования.

## Воспроизведение анализа

Основные расчёты находятся в
[`Exchange_Analysis_Clean.ipynb`](notebooks/Exchange_Analysis_Clean.ipynb).
Notebook последовательно загружает исходную таблицу, очищает данные,
нормализует показатели, применяет веса и формирует рейтинги.

Диаграммы для отчёта можно пересоздать командой из папки `exchange_research`:

```bash
python3 scripts/build_crypto_charts.py
```
