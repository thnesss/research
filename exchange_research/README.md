# Исследование: ТОП-5 глобальных бирж

## Цель:

Провести мини-исследование глобальных бирж (крипто и деривативов) и выбрать пять наиболее интересных.

## Этапы исследования:

- Определить критерии отбора
- Собрать данные
- Проверить источники
- Сравнить биржи
- Выбрать пять наиболее подходящих

## Структура проекта

- `materials/` — рабочие материалы и собранная информация
- `data/` — исходные данные для анализа
- `notebooks/` — анализ в Jupyter Notebook
- `results/` — результаты исследования
