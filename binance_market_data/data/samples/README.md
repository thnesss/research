# Примеры исходных записей

Здесь находятся два коротких примера `bookTicker` для BTC:

- `btcusdt_spot_sample.csv` — спотовый рынок;
- `btcusdt_usdm_futures_sample.csv` — бессрочный USD-M контракт.

Эти файлы нужны только для понимания структуры столбцов. Они были записаны в
разное время и не используются для расчёта отклонения или анализа фандинга.

Полные файлы слишком большие для GitHub и хранятся отдельно.
