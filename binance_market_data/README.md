# Исследование рынка Binance

В этой папке собраны данные и расчёты, которые я использовала, чтобы посмотреть,
как цена бессрочного контракта Binance отличается от обычной спотовой цены и
что происходит рядом с расчётом фандинга.

## Главный вопрос

Фандинг нужен для того, чтобы цена бессрочного контракта не уходила слишком
далеко от цены базового актива. Я проверила:

- насколько большим было отклонение BTC и ETH;
- уменьшалось ли оно сразу после расчёта фандинга;
- можно ли использовать этот результат для сравнения с SPB Биржей.

Короткий итог находится в [`ANALYSIS.md`](ANALYSIS.md). Все последовательные
расчёты и графики оставлены в одном основном файле —
[`binance_funding_analysis.ipynb`](notebooks/binance_funding_analysis.ipynb).

## Что получилось

- 3 сентября 2026 года бессрочный контракт Binance большую часть времени был
  примерно на `0,04%` ниже спотовой цены.
- Типичное абсолютное отклонение составило `0,0443%` для BTC и `0,0422%` для
  ETH.
- После фандинга отклонение вело себя по-разному. Иногда оно уменьшалось,
  иногда увеличивалось.
- Одного дня недостаточно, чтобы оценить долгосрочную эффективность механизма.

Важно: это сравнение контракта со спотовой ценой. Официальный фандинг Binance
рассчитывается по Premium Index, в котором используются индексная цена и цены с
учётом ликвидности. Поэтому наблюдаемое отклонение не является официальным
Premium Index Binance.

## Структура

- [`ANALYSIS.md`](ANALYSIS.md) — итоговые выводы простым языком;
- [`data/results_summary.csv`](data/results_summary.csv) — компактная таблица
  проверенных результатов;
- [`notebooks/`](notebooks/) — один основной Jupyter Notebook;
- [`scripts/`](scripts/) — программа сбора Binance `bookTicker`;
- [`data/samples/`](data/samples/) — небольшие примеры исходных записей;
- [`requirements.txt`](requirements.txt) — библиотеки для запуска.

Большие исходные CSV не хранятся в GitHub. Старые ноутбуки и отдельные
многочисленные HTML-копии графиков удалены из рабочей папки. При необходимости
они остаются доступными в истории Git.

## Как запустить сборщик

```bash
pip install -r requirements.txt
python3 scripts/binance_collector.py spot btcusdt
python3 scripts/binance_collector.py usdm_futures btcusdt
```

Для ETH вместо `btcusdt` используется `ethusdt`. Публичные данные `bookTicker`
не требуют API-ключа.

## Ограничение исследования

В данных были пропуски, в том числе непосредственно перед расчётами фандинга в
11:00 и 19:00 по Москве. На графиках их нельзя соединять линией и принимать за
реальные наблюдения. Поэтому вывод о влиянии фандинга пока считается
предварительным.
